One image summing up the world news of Friday 20 November 2026, drawn as a
broadsheet front page. Round 2 leads with the first-ever Trump–Xi–Putin
three-way summit in Shenzhen and its four-point "peace declaration", with the
UN court's first-ever genocide ruling against a state (Myanmar, 9–6) and the
Houthi missile strike on Riyadh's wealth-fund tower as second stories, plus a
day-in-brief strip (AI sell-off, COP31, Gaza, Kenya Ebola).

`main.ts` (Node 22, standard library only) copies the pre-rendered `entry.png`
to the output directory. `render.py` is the Pillow script that drew the page.
